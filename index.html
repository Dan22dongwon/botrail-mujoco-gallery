로봇 공정 시뮬레이션 갤러리

botrail로 설계한 로봇 셀을 MuJoCo와 Isaac Sim 물리 엔진에서 다시 돌려 본 결과입니다. 카드를 누르면 3D로 재생되고, 위쪽 버튼으로 botrail 계획 · MuJoCo · Isaac Sim을 바꿔 볼 수 있어요.

    MuJoCo로 다시 돌려서 새로 알 수 있는 것

    모터가 버티는지

    로봇 무게·관성을 넣고 계획 동작에 필요한 관절 토크를 계산해, 모터 한계 대비 몇 %인지 봅니다.

    실제로 따라가는지

    계획한 경로를 물리 로봇이 몇 mm 차이로 따라가는지 잽니다. 무거운 공구나 빠른 동작에서 벌어지는 차이가 드러나요.

    숨어 있던 겹침

    그리퍼가 손잡이에 닿는 순간, 로봇끼리 스치는 순간처럼 계획 단계에서 안 보이던 접촉을 찾습니다.

    모델 정보의 빈칸

    무게가 빠진 그리퍼, 자리만 채운 모터 한계처럼 로봇 모델에서 실제와 다른 값을 찾아 알려 줍니다.

    빠르고 가볍게 반복

    GPU 없이 실제 시간보다 5~7배 빨리 돌아서, 설계를 바꿀 때마다 자동으로 다시 확인할 수 있어요.

    학습·대량 실험으로 확장

    MuJoCo 형식이라 강화학습, 수천 개 병렬 실험, 다른 로봇 도구로 바로 가져갈 수 있습니다.

    결과 보는 법 — 잘 돌아가요: 로봇이 계획대로 움직였고 부딪힌 곳이 없음. 확인 필요: 겹침이나 경로 이탈이 있어 원인을 봐야 함 (실제 문제일 수도, 로봇 모델 정보가 부족해서일 수도 있어요). 수치는 각 화면의 "자세히"에 있어요.
